# Code of Conduct

This project is intended to be a practical and respectful collaboration space.

## Expected Behavior

- Be clear, constructive, and specific.
- Discuss technical disagreements with evidence and reproducible examples.
- Respect different experience levels and working contexts.
- Avoid sharing confidential SQL, credentials, business data, or internal operational details.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing another party's private information.
- Intentionally submitting malicious code, secrets, or misleading reports.

## Enforcement

Project maintainers may edit, reject, or remove issues, pull requests, comments, and contributions that do not follow this code of conduct.

If you need to report a concern, contact the project maintainers through the repository's private security or maintainer contact channel.
