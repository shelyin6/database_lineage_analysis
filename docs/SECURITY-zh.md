# 安全策略

## 支持的版本

除非仓库定义了发布分支，否则 `main` 分支是当前活跃的开发分支。

## 报告漏洞

请不要在公开 issue 中披露安全问题。

请私下向仓库维护者报告漏洞，并包含以下信息：

- 受影响的版本或提交。
- 重现步骤。
- 影响范围和预期行为。
- 相关日志或经过脱敏的代码片段。

## 敏感数据

本应用用于解析本地 SQL 文件。在发布 issue、示例、截图或测试夹具之前，请移除：

- 如果属于机密，请移除真实数据库名称、表名、字段名和存储过程逻辑。
- 内部系统中的业务 SQL 文件。
- SQLite 运行时数据库，例如 `metadata.sqlite`。
- 会话 Cookie、密码、访问令牌、私钥和内部网络地址。

## 默认账户

开源项目包含用于简单离线部署的固定演示/本地账户。在生产环境或公开部署中，请检查身份认证模型，并使用组织的身份提供商或更完善的账户管理流程替代固定凭据。
